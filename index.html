Launch a token on Ammora

Create your own launch Config, issue a token on its bonding curve, trade it up to graduation, then claim the fees it earns. Everything runs in your browser against the Ammora protocol contracts on GIWA Sepolia — built with @ammora-protocol/sdk 0.3.9.

Testnet only. Ammora is beta software that has not completed an independent security audit, and GIWA Sepolia ETH/WETH have no real value. Never use this flow with real funds.
